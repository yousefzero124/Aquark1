# عقارك — Aqarak

موقع عقارات لمدينة بورسعيد (HTML + CSS + JavaScript) + سيرفر صغير (Node.js) للحسابات والإعلانات والمحادثات.

> كل تفاصيل المشروع (المميزات، الصفحات، قاعدة البيانات، الـ API، الأمان): [PROJECT.md](PROJECT.md)

## البيانات بتتحفظ فين؟

| | فين |
|---|---|
| **الموقع على Vercel** | قاعدة بيانات Postgres (Neon) — كل الناس بيشوفوا نفس البيانات من أي جهاز |
| **على جهازك (Start Server)** | ملف `data/db.json` — للتجربة بس (مش بيترفع) |

اللي محفوظ في قاعدة البيانات: الحسابات، إعلانات البروكرز (بصورها وصورة الـ 360)، سجل الأسعار، المفضلة،
الإشعارات، المحادثات، البحث المحفوظ، وإخفاء/تمييز/توثيق الإعلانات من لوحة التحكم.
الـ 209 عقار التجريبي موجودين في الكود (`public/js/data.js`) مش في قاعدة البيانات.

- كلمات المرور متشفّرة (scrypt) — محدش يقدر يقراها، ولا حتى انت.
- الجلسة كوكي آمنة (httpOnly) مدتها 30 يوم. لو حد غيّر الباسورد، الجلسات القديمة بتقفل.
- كود الأدمن على السيرفر (مش ظاهر في ملفات الموقع).
- حذف حساب بيمسح معاه إعلاناته ومحادثاته ومفضلته وإشعاراته.

> **مساحة قاعدة البيانات:** صور الإعلانات بتتحفظ جوه قاعدة البيانات. خطة Neon المجانية فيها 0.5 جيجا —
> تكفي حوالي 300–500 إعلان بصورهم. لو الموقع كبر، الخطوة الجاية نقل الصور لـ Vercel Blob أو Cloudflare R2.

## المميزات

| الميزة | ازاي بتشتغل |
|---|---|
| **جولة 360°** | البروكر بيرفع صورة بانوراما (اختياري) في "اعرض عقارك". العقار بيظهر عليه علامة 360° وفي التفاصيل زرار "جولة 360°". فيه فلتر "فيه جولة 360° بس". (المكتبة: Pannellum — مجانية) |
| **سجل السعر** | رسم بياني في تفاصيل كل عقار. البروكر بيغيّر السعر من "إعلاناتي" ← "تعديل السعر"، والسعر الجديد بيتسجل. لو السعر نزل، اللي حافظين العقار في المفضلة بيجيلهم إشعار |
| **الرسايل** | زرار "ابعت رسالة" في تفاصيل أي إعلان حقيقي ← صفحة الرسايل. الرسايل الجديدة بتظهر لوحدها (كل 3 ثواني)، وأيقونة الرسايل في الهيدر عليها عدد الجديد. (العقارات التجريبية مالهاش صاحب حقيقي فمفيش فيها محادثة) |
| **البحث المحفوظ** | في صفحة العقارات: ظبط الفلاتر ← "احفظ البحث". أول ما بروكر ينزل عقار مطابق بيجيلك إشعار. البحث المحفوظ بيظهر تحت الفلاتر (دوس عليه يرجّع نفس النتايج) |
| **اللوحات** | كل نوع حساب ليه لوحة: المشتري والمستثمر والبروكر في `dashboard.html`، والأدمن في لوحة التحكم (فيها "إدارة الإعلانات" بكل العقارات) |
| **تعديل الإعلان** | صاحب الإعلان أو الأدمن: "تعديل" ← نفس فورم النشر بكل البيانات والصور والـ 360 والفيديو |
| **الفيديو** | رفع ملف فيديو (لحد 50 ميجا) أو لينك يوتيوب في فورم الإعلان. على الموقع رفع الملفات محتاج Vercel Blob (الخطوة 6) |

## تشغيل الموقع على جهازك

- دبل كليك على **Start Server.bat** ← الموقع بيفتح على `http://localhost:5500`
- محتاج يكون **Node.js** متسطب: https://nodejs.org
- كود الأدمن على جهازك: `2005`
- "نسيت كلمة المرور" على جهازك: الكود بيظهر على الشاشة (للتجربة).
- عشان تشارك الموقع مع حد بعيد: **Share Online.bat** (اللينك شغال طول ما الشاشة مفتوحة)
- ملحوظة: فتح الصفحات بدبل كليك (من غير السيرفر) مش هيشغّل التسجيل والدخول.
- عشان تمسح كل بيانات التجربة على جهازك: امسح الملف `data/db.json`.

## تشغيل الحسابات على Vercel (مرة واحدة بس)

> **مهم:** اعمل الخطوات دي **قبل** ما تشغّل `Publish.bat` بالتعديلات الجديدة،
> وإلا التسجيل والدخول على الموقع هيطلعوا رسالة "السيرفر لسه متظبطش".

### 1) إعدادات المشروع
افتح مشروعك على https://vercel.com ← **Settings** ← **Build and Deployment**:
- **Framework Preset**: `Other`
- **Root Directory**: **فاضي** (الريبو كله — مش `public`). لو مكتوب فيه `public` امسحه واعمل **Save**.
- سيب Build Command و Output Directory زي ما هما (ملف `vercel.json` بيظبطهم).

### 2) قاعدة البيانات (مجانية)
من المشروع ← تبويب **Storage** ← **Create Database** ← اختار **Neon** (Serverless Postgres) ← **Continue**
← اختار أقرب منطقة (مثلاً Frankfurt) والخطة المجانية ← **Create** ← **Connect** للمشروع.
Vercel هيضيف متغير `DATABASE_URL` لوحده. الجداول بتتعمل لوحدها أول ما حد يسجّل.

### 3) المتغيرات السرية
**Settings** ← **Environment Variables** ← ضيف:

| الاسم | القيمة |
|---|---|
| `SESSION_SECRET` | كلام عشوائي طويل (40 حرف أو أكتر). تقدر تطلّعه بالأمر اللي تحت الجدول |
| `ADMIN_CODE` | كود إنشاء حساب أدمن (مثلاً `2005` — أو أحسن كود أطول محدش يخمّنه) |

لتطليع `SESSION_SECRET` افتح PowerShell واكتب:
```powershell
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```
**متشاركش القيمة دي مع حد ومتحطهاش في أي ملف في المشروع.**

### 4) ارفع
شغّل **Publish.bat** ← Vercel هيبني الموقع والسيرفر مع بعض في أقل من دقيقة.
لو كنت ضفت المتغيرات بعد آخر رفعة: **Deployments** ← آخر واحدة ← **⋯** ← **Redeploy**.

### 5) جرّب
افتح الموقع ← اعمل حساب أدمن بالكود ← من جهاز أو متصفح تاني اعمل حساب عادي ← ارجع للوحة التحكم وهتلاقيه.

### 6) رفع الفيديو (Vercel Blob — مجاني)
من غيره البروكر يقدر يحط **لينك يوتيوب** بس. عشان يقدر يرفع ملف فيديو:
من المشروع ← تبويب **Storage** ← **Create Database** ← اختار **Blob** ← **Continue** ← **Create** ← **Connect** للمشروع (علّم Production).
Vercel هيضيف `BLOB_READ_WRITE_TOKEN` لوحده. بعدها **Redeploy**، واتأكد إن `videoUpload` بقى `ok` في `/api/health`.
(الخطة المجانية: 1 جيجا مساحة — حوالي 20–40 فيديو، الفيديو لحد 50 ميجا.)

### اختياري
| الاسم | لزمته |
|---|---|
| `RESEND_API_KEY` + `EMAIL_FROM` | "نسيت كلمة المرور" يبعت الكود على الإيميل (من https://resend.com — مجاني لحد 3000 إيميل في الشهر، ومحتاج دومين خاص بيك عشان `EMAIL_FROM`). من غيرهم الصفحة هتقول للمستخدم يكلّم الإدارة. |
| `GOOGLE_CLIENT_ID` | الدخول بـ Google (نفس الـ ID اللي في `config.js`) |

## راجع `public/js/config.js`

| الإعداد | تعمل إيه |
|---|---|
| `GOOGLE_CLIENT_ID` | لو عايز الدخول بـ Google: ضيف دومين موقعك في Google Cloud ← Authorized JavaScript origins (وحط نفس الـ ID في Vercel) |
| `GOOGLE_MAPS_API_KEY` | لو عايز خرايط Google: حدّد الـ key على دومين موقعك بس (HTTP referrers) |
| `HERO_VIDEO_URL` | فيديو الواجهة — تقدر تحط فيديو خاص بيك في `public/assets/` |
